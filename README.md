# 跑酷穿越挑战（网页小游戏）

这是一个纯前端跑酷小游戏：角色会自动向前冲刺，你需要不断跳跃穿越障碍。

## 新玩法说明

- **主页背景**：进入页面后即显示循环播放的视频背景。
- **开局背景**：每次点击「开始跑酷」后，游戏区域会随机切换为一张照片背景。
- **操作方式**：
  - 键盘：`空格` 或 `↑`
  - 鼠标/触屏：点击游戏区域
- **计分方式**：
  - 跑动距离会持续累计分数
  - 每跨越一个障碍会获得额外加分
- **失败条件**：与障碍物发生碰撞后本局结束。
- **最高分**：自动保存到浏览器 `localStorage`（键名：`parkourBest`）。

## 本地运行

直接双击 `index.html` 即可运行，或使用静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：`http://localhost:8000`。
