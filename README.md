# 跑酷穿越挑战 Pro（网页小游戏）

升级版纯前端跑酷小游戏，支持音乐音效、四向控制、可配置视频背景与照片资源。

## 主要功能

- **背景音乐 + 音效**：
  - 背景循环音乐（WebAudio）
  - 跳跃、成功跨越、碰撞失败音效
  - 一键静音开关
- **跑酷控制增强**：
  - `← / →` 或 `A / D`：左右移动
  - `↑ / Space / W`：起跳
  - `↓ / S`：快速下落
- **人物形象**：跑酷对象使用人物照片形象（`img.runner`）。
- **多障碍类型**：
  - 地面普通障碍
  - 高柱障碍
  - 空中障碍
- **障碍物照片化**：障碍物由随机照片贴图生成。
- **背景视频可扩展**：支持新增 MP4 URL 并切换视频。
- **游戏背景照片可扩展**：支持新增背景图片 URL，每局开始随机切换。

## 资源配置方式（页面内）

1. 在“资源配置”输入框中填入 URL。
2. 点击“添加视频 / 添加背景 / 添加障碍图”。
3. 点击“切换视频”可轮播已添加的 MP4 视频。

> 支持常见格式：`mp4 / jpg / jpeg / png / webp`

## 本地运行

```bash
python3 -m http.server 8000
```

然后访问：`http://localhost:8000`。
