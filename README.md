# 3D 跑酷穿越挑战 Pro（网页小游戏）

本版本重点支持“**本地文件夹资源读取**”与“**3D 视觉+动作跑酷**”。

## 你提出的功能已支持

- **背景视频读取本地文件夹**：可一次加载本地 MP4 文件并作为主页背景视频。
- **3D 风格画面**：游戏区域加入透视、立体光影、3D 倾斜地面与角色/障碍 3D 变换效果。
- **障碍物照片随机读取本地文件夹**：从本地图片目录加载后随机贴图生成障碍。
- **人物奔跑动画与动作反馈**：
  - 奔跑状态会切换动作帧
  - 跳跃时触发跳跃动作
  - 左右移动有方向姿态
  - 下蹲/速降有滑行动作
- **游戏画面变大 + 全屏支持**：
  - 默认扩大游戏区域
  - 支持“画面放大倍率”滑杆
  - 支持按钮和 `F` 键切换全屏
- **障碍速度可调**：速度倍率滑杆（0.6x ~ 2.5x）。
- **游戏难度可调**：简单/普通/困难（影响障碍间隔和速度加成）。

## 操作方式

- `← / →` 或 `A / D`：左右移动
- `↑ / W / Space`：跳跃
- `↓ / S`：下蹲/快速下落
- `F`：全屏切换

## 本地资源加载步骤

1. 点击“选择视频文件夹（MP4）”。
2. 点击“选择背景图片文件夹”。
3. 点击“选择障碍图片文件夹”。
4. 可选：选择“跑酷人物动作图（多选）”以替换奔跑帧。
5. 点击“开始跑酷”。

> 说明：浏览器基于安全策略，页面无法直接遍历你硬盘目录，需通过 `input[type=file]` 由你授权选择文件夹。

## 运行

```bash
python3 -m http.server 8000
```

浏览器打开：`http://localhost:8000`
